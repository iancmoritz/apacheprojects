# apacheprojects
Run Apache SWF's projects, all from your browser

The deployed site serves a project list at `/` and each project on its own route.

| project | route | what it is |
| --- | --- | --- |
| [`airflow/`](airflow/) | `/airflow/` | Apache Airflow 3.3.1 in a browser tab — API server, scheduler, worker and Postgres all WebAssembly. Static build, [deployable to Vercel](airflow/README.md#deploy-to-vercel). |
