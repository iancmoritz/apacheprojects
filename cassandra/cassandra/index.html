Apache Cassandra 4.1.12 — CheerpJ

idle

Every node here is real Apache Cassandra, running in this tab. Each Web Worker holds one CheerpJ JVM running Cassandra 4.1.12, with its own commitlog and SSTables in a virtual filesystem. Cassandra's TCP transport is replaced by postMessage — the bytes are Cassandra's own serialized internode messages — so gossip, the token ring, replica selection, digest reads, hints and consistency levels are all Cassandra's own code. A cold start is slow: the seed node replays a real Cassandra startup (a couple of minutes), and the other nodes only join once it is answering gossip.
